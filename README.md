# .github
DevPrax organization profile and community standards

This repository contains the [DevPrax organization profile](profile/README.md) and shared community guidance:

- [Contributing](CONTRIBUTING.md): proposing changes, testing, and submitting pull requests.
- [Code of Conduct](CODE_OF_CONDUCT.md): community standards, enforcement, and reporting options.
- [Security Policy](SECURITY.md): vulnerability reporting and coordinated disclosure.
- [Support](SUPPORT.md): questions, bug reports, and feature requests.
- [Issue forms](.github/ISSUE_TEMPLATE): structured bug reports and feature requests.
- [Pull request template](.github/PULL_REQUEST_TEMPLATE.md): summary, validation, and compatibility checklist.

GitHub uses these as defaults for DevPrax repositories that do not provide their own corresponding files. This `.github` repository must be public for organization defaults to apply. A repository with its own issue templates or issue-template configuration overrides the entire shared issue-template directory. See [GitHub's default community health file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).

## Reporting setup

There is currently no designated private email address for security or code-of-conduct reports. The policies describe this limitation and the available next steps. Maintainers should enable GitHub private vulnerability reporting in each supported repository and update the policies when a dedicated private reporting contact is established. Adding these files does not change repository settings.
