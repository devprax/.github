# DevPrax

**Engineering practical tools. Open by design.**

DevPrax is an independent open-source initiative focused on creating original, useful, and thoughtfully engineered tools for developers and engineering teams.

We believe great developer tools should be practical, extensible, reliable, and accessible.

### What we build

- **Developer productivity** — Tools that simplify everyday engineering workflows.
- **AI and automation** — Extensible systems that connect models, tools, and real-world workflows.
- **Engineering infrastructure** — Utilities that make developing, testing, and maintaining software easier.
- **Open innovation** — Original solutions developed transparently with the community.

### Our projects

**[Sage Bot](https://github.com/devprax/sage-bot)**

An extensible AI assistant for Slack, supporting configurable language models and integrations with Model Context Protocol (MCP) servers.
